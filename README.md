# ROBLXO Trampoline Game
A collection of backend and frontend systems I created for a trampoline-themed game.

## Overview

This project demonstrates modular Roblox development, including:

- Client-server architecture
- RemoteEvents and RemoteFunctions
- Persistent player data
- Inventory systems
- Physics-based gameplay
- UI systems
- Input and interaction systems
- Leaderboards and time trials

## Systems

- Trampoline / Trick System
- Player Data / Inventory
- Shop
- Time Trials / Leaderboards
- UI / Client Architecture
- Networking
